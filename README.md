# SimpleCPU
This is a simple CPU that can follow a list of 16 instructions and perform addition, subtraction, and simple logic operations on 2-bit numbers. I made this to learn how to use gates, and it is a good project for people who have experience with hardware but not with gates to try.

It works in ___ steps. First, the user flips switches in a matrix to manually code the instructions. Then, the user presses run, and those switches tell the ROM, another matrix, what the instructions are. Then, the user powers on the CPU with a switch and resets the counter. Then, the clock starts pulsing 1s and 0s to the counter. The counter then increments by one every clock tick, or jumps a specific amount in certain cases
